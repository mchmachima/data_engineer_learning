## Overview

วิดีโอนี้สรุปวิธีการเก็บรวบรวมข้อมูลที่ Data Engineer ใช้งานจริง ตั้งแต่ query language ไปจนถึง data exchange platform

---

## Methods Overview

| Method                  | Description                                                                                     |
| ----------------------- | ----------------------------------------------------------------------------------------------- |
| SQL / Query Languages   | ดึงข้อมูลจากฐานข้อมูลเชิงสัมพันธ์; ที่เทียบเท่าใน NoSQL: CQL (Cassandra), GraphQL (Neo4J)       |
| APIs                    | เข้าถึงข้อมูลผ่าน endpoint จากฐานข้อมูล บริการเว็บ และ marketplace                              |
| Web Scraping            | ดาวน์โหลดข้อมูลเฉพาะจากหน้าเว็บตามพารามิเตอร์ที่กำหนด                                           |
| RSS Feeds               | ดักจับข้อมูลอัปเดตต่อเนื่องจากเว็บข่าวและฟอรัม                                                  |
| Data Streams            | รวบรวมข้อมูล real-time จาก IoT, GPS, โซเชียลมีเดีย                                              |
| Data Exchange Platforms | การแลกเปลี่ยนข้อมูลที่มีการกำกับดูแลระหว่างผู้ให้และผู้รับข้อมูล (AWS Data Exchange, Snowflake) |
