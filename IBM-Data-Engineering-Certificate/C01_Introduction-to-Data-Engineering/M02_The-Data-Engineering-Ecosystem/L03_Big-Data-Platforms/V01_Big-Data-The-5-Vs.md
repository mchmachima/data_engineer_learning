## Overview

วิดีโอนี้อธิบายกรอบ 5 V's ที่ใช้นิยาม Big Data ได้แก่ Velocity, Volume, Variety, Veracity และ Value

---

## The 5 V's

| V        | Definition                                                                  |
| -------- | --------------------------------------------------------------------------- |
| Velocity | ความเร็วในการสร้างข้อมูล (เช่น YouTube มีคลิปอัปโหลดทุก 60 วินาที)          |
| Volume   | ขนาดข้อมูล — สร้างขึ้นราว 2.5 ล้านล้านล้านไบต์ต่อวัน                        |
| Variety  | ความหลากหลายของประเภทและแหล่งข้อมูล (structured, social media, IoT, วิดีโอ) |
| Veracity | คุณภาพและความถูกต้อง; ข้อมูล 80% เป็น unstructured และต้องผ่านการตรวจสอบ    |
| Value    | การเปลี่ยนข้อมูลให้เกิดผลลัพธ์ที่มีความหมาย (ธุรกิจ การแพทย์ สังคม)         |
