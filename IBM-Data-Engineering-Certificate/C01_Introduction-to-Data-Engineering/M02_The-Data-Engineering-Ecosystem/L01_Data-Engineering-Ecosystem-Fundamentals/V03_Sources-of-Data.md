## Overview

วิดีโอนี้แนะนำแหล่งที่มาของข้อมูลที่ Data Engineer ต้องรู้จัก ตั้งแต่ฐานข้อมูลภายในองค์กรไปจนถึงข้อมูล streaming แบบ real-time

---

## Where Data Comes From

- **Relational Databases** — ระบบภายในองค์กร (SQL Server, Oracle, MySQL, DB2)
- **Flat Files / XML** — ข้อมูลที่เผยแพร่จากภาครัฐและผู้ให้บริการข้อมูล
- **APIs & Web Services** — Twitter, ตลาดหุ้น, บริการตรวจสอบความถูกต้องของข้อมูล
- **Web Scraping** — เปรียบเทียบราคา, หา lead, ข้อมูลฝึกโมเดล ML; เครื่องมือ: BeautifulSoup, Scrapy, Selenium
- **Data Streams** — IoT, GPS, เหตุการณ์แบบ real-time; เครื่องมือ: Apache Kafka, Spark Streaming, Storm
- **RSS Feeds** — เนื้อหาที่อัปเดตจากข่าวและฟอรัม
