## Overview

วิดีโอนี้สรุปภาษาหลักที่ผู้ทำงานด้านข้อมูลใช้ ตั้งแต่ query language อย่าง SQL ไปจนถึงภาษา scripting สำหรับงาน automation

---

## Languages Overview

| Category    | Language         | Key Use                                                                               |
| ----------- | ---------------- | ------------------------------------------------------------------------------------------ |
| Query       | SQL              | มาตรฐานสำหรับฐานข้อมูลเชิงสัมพันธ์                                                          |
| Programming | Python           | ทำความสะอาดข้อมูล, ML, scripting; ไลบรารี: Pandas, NumPy, Matplotlib, BeautifulSoup           |
| Programming | R                | การวิเคราะห์เชิงสถิติ, visualization; ไลบรารี: ggplot2, dplyr                                 |
| Programming | Java             | framework big data (Hadoop, Spark เขียนด้วย Java); งานที่ต้องการความเร็วสูง                    |
| Scripting   | Unix/Linux Shell | จัดการไฟล์, batch job, ดูแลระบบ                                                             |
| Scripting   | PowerShell       | ข้อมูลแบบมีโครงสร้าง (JSON, CSV, XML), automation, ดูแลระบบ cloud                             |
