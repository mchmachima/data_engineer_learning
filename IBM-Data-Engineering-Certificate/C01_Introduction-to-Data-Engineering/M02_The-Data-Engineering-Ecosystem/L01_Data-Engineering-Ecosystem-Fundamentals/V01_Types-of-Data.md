## Overview

วิดีโอนี้แนะนำ 3 ประเภทของข้อมูล ได้แก่ structured, semi-structured และ unstructured data พร้อมทั้งบอกว่าแต่ละประเภทมักถูกจัดเก็บที่ไหน

---

## The 3 Types of Data

| Type            | Description                          | Storage                     |
| --------------- | --------------------------------------- | ------------------------------ |
| Structured      | มี schema ตายตัว จัดเก็บเป็นแถวและคอลัมน์   | RDBMS, ฐานข้อมูล SQL             |
| Semi-structured | มีโครงสร้างบางส่วน ไม่มี schema ตายตัว      | XML, JSON, NoSQL                |
| Unstructured    | ไม่มีรูปแบบที่กำหนดไว้ล่วงหน้า              | ไฟล์ทั่วไป, NoSQL, Data Lakes      |

---

## 📖 Key Terms & Glossary

| Term (ศัพท์)     | คำอธิบาย (ภาษาไทย)                                                |
| ----------------- | -------------------------------------------------------------------- |
| Structured Data   | ข้อมูลที่มี schema ตายตัว จัดเก็บเป็นแถวและคอลัมน์ในฐานข้อมูลเชิงสัมพันธ์  |
| Semi-structured   | ข้อมูลที่มีการจัดระเบียบบางส่วน (เช่น XML, JSON) แต่ไม่มี schema ตายตัว    |
| Unstructured      | ข้อมูลที่ไม่มีรูปแบบกำหนดไว้ล่วงหน้า (เช่น รูปภาพ วิดีโอ โพสต์โซเชียลมีเดีย)   |
