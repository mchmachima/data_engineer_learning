## Common File Formats

| Format    | Best For                                                                     |
| --------- | -------------------------------------------------------------------------------- |
| CSV / TSV | ข้อมูลตารางแบบง่าย; CSV ใช้งานทั่วไป, TSV ใช้เมื่อค่าข้อมูลมี comma อยู่ภายใน       |
| XLSX      | Excel workbook ที่มีหลายชีทและสูตรคำนวณ                                          |
| XML       | การแชร์ข้อมูลแบบมีลำดับชั้น (hierarchical) ข้ามแพลตฟอร์ม                          |
| JSON      | Web API และการส่งข้อมูล; รองรับข้อมูลได้ทุกขนาดและทุกประเภท                        |
| PDF       | เอกสารที่ต้องการการแสดงผลที่สม่ำเสมอข้ามระบบ                                       |
