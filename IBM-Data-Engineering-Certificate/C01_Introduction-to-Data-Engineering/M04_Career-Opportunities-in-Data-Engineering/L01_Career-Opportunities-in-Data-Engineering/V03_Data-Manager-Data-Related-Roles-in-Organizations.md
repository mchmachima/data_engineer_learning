## Overview

วิดีโอนี้จัดกลุ่มบทบาทที่เกี่ยวข้องกับข้อมูลในองค์กรออกเป็น 4 หมวด ได้แก่ Technical, Analytical, Governance & Privacy และ Leadership พร้อมอธิบายว่า AI จะส่งผลต่อแต่ละหมวดอย่างไร

---

## Role Categories

| Category                  | Roles                                                                                                                           |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Technical**                | Data Engineer, Machine Learning Engineer, Database Administrator (DBA)                                                                  |
| **Analytical**               | Data Analyst, Data Scientist                                                                                                             |
| **Governance & Privacy**     | Data Governance Associate, Data Steward, Compliance Specialist, Governance Manager, Data Ethics Steward, Data Privacy Officer            |
| **Leadership**               | Data Architect, Chief Data Officer (CDO), Data Ethics Officer                                                                            |

---

## Technical Roles

- โฟกัส: infrastructure, สถาปัตยกรรม, machine learning
- ต้องการ: ทักษะ programming, ความรู้ฐานข้อมูล, การจัดการ dataset ขนาดใหญ่
- จุดเริ่มต้น: ตำแหน่ง junior data engineering — ทำงานกับ pipeline และ infrastructure ภายใต้การดูแลของ senior
- **ML Engineer:** พัฒนาอัลกอริทึมและโมเดล ML
- **DBA:** ดูแลและบำรุงรักษาฐานข้อมูลด้าน performance และ security
- **ผลกระทบของ AI:** AI จะทำงาน routine และ optimize โค้ดโดยอัตโนมัติ ทำให้คนโฟกัสกับการออกแบบระดับสูงและการผสาน AI ได้มากขึ้น

---

## Analytical Roles

- โฟกัส: สำรวจข้อมูลเพื่อค้นหาและสื่อสาร insight
- **Data Analyst:** รายงานต่อ data scientist; สร้าง visualization, dashboard และรายงาน
- **Data Scientist:** นำทีม; ใช้เทคนิคทางสถิติ; นำเสนอผลลัพธ์ต่อองค์กร
- **ผลกระทบของ AI:** AI จะทำงานวิเคราะห์หลายอย่างโดยอัตโนมัติ แต่การเล่าเรื่องและการตัดสินใจของมนุษย์ยังจำเป็นอยู่

---

## Governance and Privacy Roles

- โฟกัส: ทำให้การเก็บ จัดเก็บ และใช้ข้อมูลเป็นไปตามมาตรฐานทางกฎหมาย จริยธรรม และองค์กร
- **Data Governance Associate:** ตำแหน่งระดับเริ่มต้น; สนับสนุน governance ผ่านเอกสารและคุณภาพข้อมูล
- **Governance Manager:** กำหนดและบังคับใช้นโยบาย; รักษาความถูกต้องและความปลอดภัยของข้อมูล
- **Data Steward:** ดูแลคุณภาพ ความถูกต้อง และการจัดการข้อมูลอย่างเหมาะสม; ป้องกัน bias จาก AI
- **Data Ethics Steward:** ดูแลให้แนวปฏิบัติด้านข้อมูลสอดคล้องกับค่านิยมทางสังคมและหลักจริยธรรม (กว้างกว่าแค่ compliance)
- **ผลกระทบของ AI:** สาขา governance คาดว่าจะเติบโตเร็วเมื่อ AI ถูกนำมาใช้มากขึ้น; AI ช่วยเฝ้าติดตามนโยบาย ทำให้คนมีเวลาโฟกัสกลยุทธ์และจริยธรรมมากขึ้น

---

## Leadership Roles

- **Data Architect, CDO, Data Ethics Officer** — กำหนดวิสัยทัศน์ นโยบาย และกลยุทธ์ข้อมูลขององค์กร
- ตัดสินว่า AI ควรถูกใช้อย่างไร ที่ไหน และทำไม
- **ผลกระทบของ AI:** ผู้นำกลุ่มนี้เป็นผู้ตัดสินใจขั้นสุดท้ายเกี่ยวกับบทบาทของ AI ในธุรกิจ
