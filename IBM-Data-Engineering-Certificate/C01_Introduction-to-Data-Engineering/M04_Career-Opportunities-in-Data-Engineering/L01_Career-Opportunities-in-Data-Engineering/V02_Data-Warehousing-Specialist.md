## Overview

วิดีโอนี้เจาะลึกตำแหน่ง Data Warehousing Specialist เป็นตัวอย่างเฉพาะทางของ Data Engineer ครอบคลุมหน้าที่หลัก โอกาสในตลาดงาน ทักษะที่ต้องมี และเครื่องมือที่ใช้งานจริง

---

## Description

Data Warehousing Specialist ออกแบบ สร้างโมเดล และ implement กิจกรรม data warehousing ขององค์กร โปรแกรมและตั้งค่าคลังฐานข้อมูล และสนับสนุนผู้ใช้งาน data warehouse เป็นสาขาเฉพาะทางย่อยของ Data Engineer โดยรวม

---

## Opportunity Estimates

- อัตราการเติบโตที่คาดการณ์: **8–10% ต่อปี** ในช่วง 10 ปีข้างหน้า (สูงกว่าค่าเฉลี่ย)

- เงินเดือนกลางในสหรัฐฯ: **$110,168** (ที่มา: salary.com)

## Key Tasks

- พัฒนากระบวนการ ขั้นตอน และซอฟต์แวร์สำหรับการจัดการข้อมูลระดับองค์กร
- ออกแบบ สร้างโมเดล หรือ implement กิจกรรม data warehousing ขององค์กร
- พัฒนาและดูแลมาตรฐานสำหรับองค์ประกอบของ data warehouse (สถาปัตยกรรม โมเดล เครื่องมือ ฐานข้อมูล)
- เขียน/แก้ไขโปรแกรมให้ตรงตามความต้องการของลูกค้า
- สร้างเอกสาร: metadata, entity relationship diagram, business process flow
- ออกแบบและดูแลระบบ data warehouse โดยสมดุลระหว่างการเข้าถึงข้อมูล batch loading และการใช้ทรัพยากร
- implement กฎทางธุรกิจผ่าน stored procedure, middleware หรือเทคโนโลยีอื่นๆ
- สร้าง test plan และ script (ตั้งแต่ unit จนถึง integration testing)

## Technical Skills

**Specialized Knowledge**

- programming, systems analysis, data architecture, การจัดการและวิเคราะห์ข้อมูล
- data pipeline, ETL, business intelligence, data warehousing
- normalization ของฐานข้อมูล, ฐานข้อมูลเชิงสัมพันธ์, การย้ายข้อมูล
- การจัดการ metadata, แพลตฟอร์ม data integration
- cloud data infrastructure, database administration (รวมถึง Big Data)
- data lake, data mart, data reservoir, การรวมข้อมูล IoT
- event streaming pipeline
- กฎหมายและระเบียบ: ทรัพย์สินทางปัญญา, PII, ข้อมูลลูกค้า

**Software and Tools**

- **Cloud platforms:** AWS, Microsoft Azure, GCS, SpringCloud
- **Data warehouse tools:** Snowflake, Databricks, BigQuery, Redshift, Db2
- **Data pipeline tools:** Apache Kafka, Apache Airflow, Luigi
- **Big data tools:** Apache Hadoop, Apache Spark, Apache Hive
- **Operating systems:** UNIX, Linux
- **Programming languages:** SQL, Bash, Python, R, Java, C++
- **Databases:** Cassandra, SQL Server, MySQL, PostgreSQL, DynamoDB, MongoDB, neo4j, Oracle, IBM Db2, Apache Solr
- **Metadata management:** CA Erwin, Oracle Warehouse Builder, Talend Data Fabric, Alation, IBM Watson Knowledge Catalog, Informatica, Azure Data Catalog และอื่นๆ
- **BI tools:** Power BI, Tableau, Qlik, Cognos, MicroStrategy, Domo, SAP Lumira, SAS Analytics และอื่นๆ
- **Other:** Git, Agile, API development

## Career Progression

Junior/Associate → Data Warehouse Specialist → Senior → Lead → Principal

- บทบาทนี้คือบทบาท Data Engineering ที่เน้นด้าน Data Warehousing โดยเฉพาะ
- ทีมเล็ก: ได้มีส่วนร่วมในทุกขั้นตอนของ data engineering lifecycle
- ทีมใหญ่: หา niche เฉพาะแล้วก้าวหน้าภายในสาขานั้น
- ต้องเรียนรู้เครื่องมือและเทคโนโลยีใหม่ๆ อย่างต่อเนื่องเสมอ
