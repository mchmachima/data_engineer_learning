## Overview

วิดีโอนี้สำรวจตลาดงานด้าน data engineering ตำแหน่งงานที่แตกแขนงออกไป เส้นทางความก้าวหน้าในสายอาชีพ และบทบาทใหม่ๆ ที่กำลังเกิดขึ้นอย่าง Big Data Engineer และ ML Engineer

---

## Job Market Overview

- LinkedIn's 2020 Emerging Jobs Report: data engineering เป็นหนึ่งใน 10 อาชีพที่มี "การเติบโตอย่างมหาศาล" ในสหรัฐฯ
- Dice Tech Job Report 2020: data engineering เป็น **อาชีพเทคโนโลยีที่เติบโตเร็วที่สุด** ด้วยอัตราการเติบโต **50% ต่อปี**
- อุตสาหกรรมที่ต้องการบุคลากรด้าน data engineering มากที่สุด: **สุขภาพ เทคโนโลยี และที่ปรึกษา**
- Glassdoor's Best Jobs in America 2020: data engineering ติดอันดับ 10 อันดับแรก (เกณฑ์: ศักยภาพรายได้ ความพึงพอใจในงาน จำนวนตำแหน่งงานเปิด)

## Job Roles and Titles

บทบาทด้าน data engineering มีความยืดหยุ่นและแตกต่างกันไปตามแต่ละบริษัท สาขาที่พบบ่อย ได้แก่:

| Specialization        | Example Job Titles       |
| ---------------------- | --------------------------- |
| Data Architecture       | Data Architect              |
| Database Design         | Database Architect          |
| Data Pipelines / ETL    | ETL Engineer                |
| Data Warehouses         | Data Warehouse Engineer     |
| Big Data                | Big Data Engineer           |
| Cloud Data Lakes        | Data Lake Engineer          |

ทุกบทบาทมักต้องการความรู้ด้าน: operating system, ภาษาโปรแกรม, ฐานข้อมูล, infrastructure (VM, networking, app service), และความเข้าใจการนำข้อมูลไปใช้ทางธุรกิจ

---

## Career Progression

เส้นทางความก้าวหน้าโดยทั่วไปในทีม data engineering ที่จัดตั้งแล้ว:

**Associate/Junior Data Engineer → Data Engineer → Senior Data Engineer → Lead Data Engineer → Principal Data Engineer**

- การเติบโต = ขยายทักษะเฉพาะทาง + แตกแขนงไปสาขาอื่น (เช่น data architect ที่เข้าใจ warehouse, lake, pipeline ด้วย)
- เมื่อก้าวหน้าขึ้น: ใช้เวลามากขึ้นกับการแปลงความต้องการทางธุรกิจเป็น spec ทางเทคนิค ประเมินเครื่องมือ/แพลตฟอร์ม และรับผิดชอบคุณภาพข้อมูล ความเป็นส่วนตัว และ compliance
