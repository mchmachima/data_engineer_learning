## Overview

วิดีโอนี้ปิดท้ายด้วยเส้นทางการเข้าสู่สายอาชีพ data engineering วิธีเริ่มต้น และแนวคิดที่จำเป็นต่อการเติบโตในสายงานที่เปลี่ยนแปลงเร็วนี้

---

## Entry Routes

1. **ปริญญาทางวิชาการ** — สาขา Computer Science หรือ Engineering (บางบริษัทให้ความสำคัญ)
2. **เรียนรู้ด้วยตนเอง / คอร์สออนไลน์** — Coursera, edX, Udacity; ออกแบบโดยมหาวิทยาลัยชั้นนำและบริษัทเทคโนโลยี; มี hands-on project และ certification ทางวิชาชีพ
3. **เปลี่ยนสายอาชีพ** — IT Support, Software Tester, Programmer, Statistician, Data Analyst, BI Analyst สามารถ re-skill มาเป็น data engineer ได้

---

## How to Start

- สร้างพื้นฐานทักษะ: ภาษา programming/query, operating system, ฐานข้อมูล
- หางาน entry-level หรือสร้าง portfolio จากโปรเจกต์ส่วนตัว
- ก้าวหน้าไปสู่ทีมที่ใหญ่ขึ้นและมีความต้องการข้อมูลที่ซับซ้อนขึ้นตามประสบการณ์ที่เพิ่มขึ้น

---

## Choosing a Path

- กำหนดเป้าหมายระยะสั้นและระยะยาวให้ชัดเจน
- เลือกสาขาเฉพาะทางเริ่มต้น (เช่น pipeline, distributed systems, data architecture) แล้วขยายออกไป
- ประสบการณ์จริงมีความสำคัญมากต่อการทำความเข้าใจให้แน่นขึ้น

---

## Key Mindset

Data Engineering เป็น **สายงานที่เปลี่ยนแปลงเร็ว** — ความอยากรู้อยากเห็น การเปิดรับการเรียนรู้ และความตื่นเต้นกับเทคโนโลยีสำคัญพอๆ กับทักษะทางเทคนิค
