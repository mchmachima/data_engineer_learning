## Overview

วิดีโอนี้นำแนวคิดจากทั้งบทเรียนมาผูกเข้าด้วยกันผ่านตัวอย่างจริง: การทำ sentiment analysis จากโซเชียลมีเดีย โดยแสดงให้เห็นว่า Data Engineer เก็บ ประมวลผล และสร้าง pipeline อัตโนมัติอย่างไร

---

## Case Study Walkthrough

| Step     | What the DE did                                                           |
| -------- | ------------------------------------------------------------------------- |
| Collect  | ดึง tweet ผ่าน API และ scrape review จากเว็บ eCommerce                    |
| Process  | สร้างโปรแกรม Python เพื่อทำความสะอาดและแปลงข้อมูลให้อยู่ในรูปแบบฐานข้อมูล |
| Pipeline | ทำ ETL แบบอัตโนมัติ ทำให้ dashboard อัปเดตแบบ real-time                   |
