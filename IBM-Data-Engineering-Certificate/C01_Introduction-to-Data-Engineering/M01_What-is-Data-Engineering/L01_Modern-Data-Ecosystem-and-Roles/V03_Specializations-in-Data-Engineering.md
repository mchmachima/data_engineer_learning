## Overview

วิดีโอนี้แนะนำบทบาทเฉพาะทางที่แตกแขนงมาจาก Data Engineer ได้แก่ Data Warehouse Engineer, Data Architect, Data Manager และ Database Administrator (DBA) พร้อมจุดเน้นของแต่ละบทบาท

---

## Specialized Roles

| Role                          | Focus                                                          |
| ----------------------------- | ---------------------------------------------------------------- |
| Data Warehouse Engineer       | สร้าง ETL pipeline, data warehouse, และ data lake สำหรับ BI       |
| Data Architect                | ออกแบบสถาปัตยกรรมข้อมูลโดยรวม กลยุทธ์การ integration และ governance |
| Data Manager                  | governance ข้อมูล, compliance, นโยบายการเข้าถึง, data literacy    |
| Database Administrator (DBA)  | ดูแลการทำงานของฐานข้อมูล, backup, performance, security          |

---

## 📖 Key Terms & Glossary

| Term (ศัพท์)   | คำอธิบาย (ภาษาไทย)                                              |
| --------------- | -------------------------------------------------------------- |
| Data Architect  | ผู้ออกแบบสถาปัตยกรรมการจัดการข้อมูลโดยรวม                        |
| DBA             | Database Administrator — ผู้ดูแลการทำงาน performance และ security ของฐานข้อมูล |
