## Overview

วิดีโอนี้สรุป 4 ขอบเขตงานหลักของ Data Engineer ตั้งแต่การเก็บข้อมูล การประมวลผล การจัดเก็บ ไปจนถึงการทำให้ข้อมูลพร้อมใช้งานสำหรับผู้ใช้ปลายทาง

---

## 4 Areas of Scope

1. **Collecting Source Data** — เครื่องมือและ workflow สำหรับดึงข้อมูลจากหลายแหล่ง ออกแบบ storage ให้รองรับการขยายตัว
2. **Processing Data** — ETL pipeline, distributed systems, คุณภาพข้อมูล, validation, compliance
3. **Storing Data** — สถาปัตยกรรมที่ขยายตัวได้; ความเป็นส่วนตัว, ความปลอดภัย, backup และ recovery
4. **Making Data Available** — API, dashboard, การควบคุมสิทธิ์การเข้าถึงสำหรับผู้ใช้ปลายทาง
