## Overview

วิดีโอนี้แนะนำ modern data ecosystem หรือเครือข่ายของแหล่งข้อมูล เครื่องมือ และผู้มีส่วนได้ส่วนเสียที่ข้อมูลไหลผ่าน อธิบายองค์ประกอบหลักของ ecosystem และ 3 ขั้นตอนที่ข้อมูลต้องผ่านตั้งแต่ต้นทางจนถึงปลายทาง รวมถึงแรงขับเคลื่อนใหม่ๆ ที่กำลังเปลี่ยนรูปแบบของ ecosystem นี้

---

## Data Ecosystem Components

Data ecosystem ประกอบด้วย:

- ข้อมูลจากแหล่งที่หลากหลาย (text, IoT, social media, ฐานข้อมูลเก่า, real-time streams)
- เครื่องมือและโครงสร้างพื้นฐานสำหรับจัดเก็บ ประมวลผล และเผยแพร่ข้อมูล
- ผู้มีส่วนได้ส่วนเสียที่นำ insight ไปใช้งานจริง

---

## 3 Stages of the Data Ecosystem

1. **Acquiring** — ดึงข้อมูลจากแหล่งต่างๆ; ความท้าทาย: ความน่าเชื่อถือ ความปลอดภัย และความถูกต้องของข้อมูล
2. **Organizing & Preparing** — ทำความสะอาด ปรับให้สอดคล้องกัน และให้เป็นไปตามข้อกำหนด; ความท้าทาย: การจัดการข้อมูลและ governance ของ repository
3. **Delivering** — ส่งมอบผ่าน API, dashboard, หรือข้อมูลดิบให้นักวิเคราะห์; ความท้าทาย: เลือก interface ที่เหมาะกับผู้ใช้แต่ละกลุ่ม

**แรงขับเคลื่อนที่กำลังเปลี่ยนแปลง ecosystem:** Cloud computing, Machine Learning, Big Data
