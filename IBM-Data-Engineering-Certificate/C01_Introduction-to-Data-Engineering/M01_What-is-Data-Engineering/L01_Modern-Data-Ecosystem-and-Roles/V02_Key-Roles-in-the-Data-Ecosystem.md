## Overview

วิดีโอนี้แนะนำ 4 บทบาทหลักในเครือข่ายข้อมูล ได้แก่ Data Engineer, Data Analyst, Data Scientist และ Business/BI Analyst พร้อมอธิบายหน้าที่หลักของแต่ละบทบาท และย้ำว่าบทบาทเหล่านี้ไม่ได้แยกขาดจากกันโดยเด็ดขาด

---

## Core Roles

| Role             | Core Function                                                             |
| ---------------- | --------------------------------------------------------------------------- |
| Data Engineer    | แปลงข้อมูลดิบให้ใช้งานได้จริง (สร้าง pipeline และ repository)               |
| Data Analyst     | ใช้ข้อมูลเพื่อสร้าง insight (หาความสัมพันธ์ รูปแบบ และทำ visualization)     |
| Data Scientist   | ใช้ข้อมูลในอดีตเพื่อพยากรณ์อนาคต (โมเดล ML/DL)                              |
| Business Analyst | แปลง insight ให้เป็นข้อเสนอแนะเชิงธุรกิจ                                    |
| BI Analyst       | เน้นแรงขับเคลื่อนของตลาด สร้างโซลูชัน BI และ dashboard                      |

> บทบาทเหล่านี้ไม่ได้แยกขาดจากกัน — ผู้เชี่ยวชาญมักเปลี่ยนบทบาทกันไปมาตลอดสายอาชีพ
